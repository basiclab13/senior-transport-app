# Development Instructions

- Build a Flutter Web application with a mobile-first UI.
- Use Firebase for authentication and data storage.
- Use fictional data only.
- Keep existing transport routes as the baseline.
- Do not allow AI to publish schedule changes automatically.
- Validate staff availability, vehicle capacity, and duplicate assignments.
- Do not expose API keys or credentials.
- Implement one feature at a time.
- After code changes, run flutter analyze and relevant tests.
- Explain modified files and any remaining issues.
