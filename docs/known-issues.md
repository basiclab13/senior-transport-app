# 별도 개선 항목

## A-2 기존 담당 직원의 결근·인계 완료 표시

- 상태: 사용자 실제 Firebase 테스트에서 확인, 후속 개선 대상. B-1 범위에서는 수정하지 않음.
- 정상 확인: 결근 등록, 코스 전체 재배정, 전체 확정과 새 담당 직원 조회.
- 문제: 기존 담당 직원의 화면에서 결근 및 인계 완료 상태를 명확하게 볼 수 없음.
- 현재 코드상 관련 흐름: 확정 시 기존 담당자의 해당 날짜·시간대 `staffSchedules` 문서가 삭제된다. 직원 화면의 경고는 배정 코스/확정 이력 존재 여부에 의존하므로, 결근 문서가 있어도 단순 미배정/미확정처럼 보일 수 있다.
- 후속 설계: 본인 결근과 미배정·인계 완료를 구분하는 상태 표시 및 안전한 인계 상태 데이터 제공을 검토한다. 단순 문서 부재만으로 인계 완료라고 추정하지 않는다. 다른 직원 일정이나 전체 일정 읽기 권한을 직원에게 열어 해결하지 않는다.
- 수용 기준: 오전·오후·종일 결근, 인계 전/초안/확정 후, 부분 인계, 결근 취소·다른 날짜를 구별하고 새로고침 후에도 본인 상태가 정확해야 한다. 기존 문서 삭제의 원자성·직원별 개인정보 경계를 유지한다.
